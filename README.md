# Rubro

Player de música offline para Windows. Não precisa instalar dependências nem usar uma conta.

## Arquivos

- `index.html`: estrutura da interface.
- `styles.css`: estilos e temas.
- `app.js`: biblioteca, leitura de tags e reprodução.

## Abrir

Abra `index.html` no Microsoft Edge ou no Google Chrome. Para importar músicas, escolha **Escolher pasta Música** e selecione a pasta `Música` do seu usuário do Windows. O navegador pedirá acesso aos arquivos escolhidos; o Rubro lê as tags ID3 e reproduz os MP3s no próprio computador.

Também é possível importar outra pasta pelo botão `+` ao lado de **Sua biblioteca**. Só arquivos MP3 são incluídos. Ao abrir o Rubro novamente, selecione a pasta de músicas outra vez.

## Recursos

- Biblioteca agrupada por artista e álbum, com discografia baseada nas tags dos arquivos.
- Reprodução, faixa anterior/próxima, busca, modo aleatório, repetição, volume e favoritas.
- Histórico de músicas reproduzidas, salvo localmente e ordenado pela reprodução mais recente.
- Temas claro e escuro, com a preferência salva no navegador.
- Equalizador gráfico de 10 bandas, pré-amplificador, Bass e Treble, com ajustes salvos localmente.
- Capas incorporadas aos MP3s e tags ID3 são lidas localmente.

O Rubro é um app web portátil, não um instalador `.exe`. Os arquivos de áudio não são enviados para a internet.
